# Security policy

This program runs commands on your machines and connects between them over SSH, so security
reports are taken seriously.

## Reporting a vulnerability

Please report it privately, through GitHub's private vulnerability reporting on this
repository, rather than in a public issue. Include what you found, how to reproduce it, and
which version or commit you tested.

You can expect an acknowledgement within a week, and a fix or a plan for one once the report
has been confirmed.

## Scope

In scope: anything that makes the program run a command the user did not choose, run it on a
machine other than the one intended, reveal a secret in its output or history, or stop a
session other than the one chosen.
